# Örnek yanıtlar

Canlı API’den alınmış JSON örnekleri.

| Dosya | İstek |
|-------|--------|
| `place-ist.json` | `GET /place.php?code=ist&lang=tr` |
| `route-ist-cdg.json` | `GET /place.php?from=ist&to=cdg&lang=tr` |
| `search-istanbul.json` | `GET /place.php?search=istanbul&lang=tr&limit=5` |
| `health.json` | `GET /place.php?health=1` |

Canlı: [places.alikara.com.tr](https://places.alikara.com.tr)
